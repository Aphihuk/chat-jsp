1. PROJECT OVERVIEW (ภาพรวมโปรเจกต์)
================================================================================

Chat-JSP เป็นเว็บแอปพลิเคชันแชทออนไลน์ที่ออกแบบให้คล้ายกับ LINE โดยพัฒนาด้วยเทคโนโลยี Java
รองรับการส่งข้อความแบบ Real-time ระหว่างผู้ใช้หลายคน พร้อมฟีเจอร์การสมัครสมาชิกและเข้าสู่ระบบ

คุณสมบัติหลัก:
- ✅ ระบบสมัครสมาชิกและเข้าสู่ระบบ
- ✅ อินเทอร์เฟซแชทคล้าย LINE (สีเขียว, ฟองข้อความ)
- ✅ ส่งและรับข้อความแบบ Real-time
- ✅ รายชื่อผู้ติดต่อ
- ✅ ฐานข้อมูล MySQL
- ✅ Responsive Design สำหรับอุปกรณ์ต่างๆ

2. TECHNOLOGIES USED (เทคโนโลยีที่ใช้)
================================================================================

Backend (เซิร์ฟเวอร์):
- Java Servlet API (Jakarta EE)
- JSP (JavaServer Pages) สำหรับ Views

Frontend (ไคลเอนต์):

- Font Awesome สำหรับไอคอน

Server & Tools:
- Apache Tomcat 10.1.48 เป็น Web Server
- MySQL JDBC Driver สำหรับเชื่อมต่อฐานข้อมูล
- Git สำหรับ Version Control

3. ARCHITECTURE & CODE STRUCTURE (สถาปัตยกรรมและโครงสร้างโค้ด)
================================================================================

โปรเจกต์นี้ใช้รูปแบบ MVC (Model-View-Controller) แบบง่าย:

Model (ข้อมูล):
- Message.java - POJO สำหรับข้อความ
- User data เก็บในฐานข้อมูล

View (การแสดงผล):
- index.jsp - หน้าแรก (redirect)
- welcome.jsp - หน้ายินดีต้อนรับ
- login.jsp - หน้าเข้าสู่ระบบ
- signup.jsp - หน้าสมัครสมาชิก
- chat.jsp - หน้าแชทหลัก

Controller (ควบคุม):
- LoginServlet.java - จัดการเข้าสู่ระบบ
- SignupServlet.java - จัดการสมัครสมาชิก
- LogoutServlet.java - จัดการออกจากระบบ
- SendMessageServlet.java - จัดการส่งข้อความ
- GetMessagesServlet.java - ดึงข้อความ
- GetLastMessageServlet.java - ดึงข้อความล่าสุด

Data Access (การเข้าถึงข้อมูล):
- MessageDAO.java - จัดการ CRUD ข้อความ
- DBconnect.java - จัดการการเชื่อมต่อฐานข้อมูล

โครงสร้างไฟล์:
```
chat-jsp/
├── src/
│   ├── config/db/DBconnect.java       # Database connection
│   ├── dao/MessageDAO.java           # Data Access Object
│   ├── model/Message.java            # Data Model
│   ├── servlet/*.java                # Controllers
│   └── page/*.jsp                    # Views
├── WEB-INF/
│   ├── web.xml                       # Deployment descriptor
│   └── lib/mysql-connector.jar       # Database driver
├── *.css, *.js                       # Frontend assets
└── database.sql                      # Database schema
```

4. WORKING FLOW & PRINCIPLES (หลักการทำงานและโฟลว์)
================================================================================

หลักการทำงานหลัก:
1. Polling: ใช้การตรวจสอบข้อความใหม่ทุก 2 วินาที (ไม่ใช่ WebSocket)
2. Session Management: ใช้ HttpSession ในการจัดการสถานะการล็อกอิน
3. AJAX: ใช้ XMLHttpRequest สำหรับการส่งข้อมูลแบบอะซิงโครนัส
4. MVC Pattern: แยกความรับผิดชอบของแต่ละส่วนอย่างชัดเจน

โฟลว์การทำงานของผู้ใช้:

1. เข้าถึงเว็บไซต์ (index.jsp)
   ├── ถ้ายังไม่ได้ล็อกอิน → welcome.jsp
   └── ถ้าล็อกอินแล้ว → chat.jsp

2. สมัครสมาชิก/เข้าสู่ระบบ
   ├── SignupServlet.java จัดการสมัคร → เก็บในตาราง users
   └── LoginServlet.java จัดการล็อกอิน → ตั้งค่า session

3. หน้าแชทหลัก (chat.jsp)
   ├── โหลดรายชื่อผู้ติดต่อจากฐานข้อมูล
   ├── คลิกเลือกผู้ติดต่อ → โหลดข้อความเก่า
   └── เริ่ม polling สำหรับข้อความใหม่

4. ส่งข้อความ
   ├── พิมพ์ข้อความ → กด Enter หรือปุ่มส่ง
   ├── AJAX call ไป SendMessageServlet.java
   ├── เก็บในตาราง messages
   └── อัปเดตหน้าจอ

5. รับข้อความ
   ├── Polling ทุก 2 วินาที
   ├── GetMessagesServlet.java ส่งข้อความใหม่
   └── แสดงใน chat interface

5. KEY COMPONENTS & FUNCTIONS (ส่วนประกอบและฟังก์ชันสำคัญ)
================================================================================

5.1 Database Connection (DBconnect.java)
- จัดการการเชื่อมต่อ MySQL
- ใช้ Singleton pattern
- จัดการ Connection pooling แบบง่าย

5.2 Message Model (Message.java)
- POJO เก็บข้อมูลข้อความ
- Fields: id, fromUser, toUser, message, timestamp
- Getters/Setters methods

5.3 MessageDAO (MessageDAO.java)
- sendMessage(): เพิ่มข้อความใหม่
- getMessages(): ดึงข้อความระหว่าง 2 ผู้ใช้
- getLastMessages(): ดึงข้อความล่าสุดสำหรับ preview

5.4 Servlets (Controllers)
- SendMessageServlet: จัดการ POST request สำหรับส่งข้อความ
- GetMessagesServlet: จัดการ GET request สำหรับดึงข้อความ
- LoginServlet: ตรวจสอบ username/password
- SignupServlet: เพิ่มผู้ใช้ใหม่

5.5 Frontend (chat.js)
- loadMessages(): โหลดและแสดงข้อความ
- sendMessage(): ส่งข้อความใหม่
- startMessagePolling(): เริ่ม polling สำหรับข้อความใหม่
- displayMessages(): จัดรูปแบบและแสดงข้อความ

6. DATABASE SCHEMA (โครงสร้างฐานข้อมูล)
================================================================================

ตาราง users:
- id (INT, PRIMARY KEY, AUTO_INCREMENT)
- firstname (VARCHAR(50))
- lastname (VARCHAR(50))
- username (VARCHAR(50), UNIQUE)
- password (VARCHAR(255)) - ควร hash ในโปรดักชัน
- email (VARCHAR(100))
- phone (VARCHAR(20))
- created_at (TIMESTAMP)

ตาราง messages:
- id (INT, PRIMARY KEY, AUTO_INCREMENT)
- from_user (VARCHAR(50))
- to_user (VARCHAR(50))
- message (TEXT)
- timestamp (TIMESTAMP)

9. DEPLOYMENT & RUNNING (การติดตั้งและรัน)
================================================================================

1. ตั้งค่าฐานข้อมูล: รัน database.sql ใน MySQL
2. แก้ไข DBconnect.java ให้ตรงกับข้อมูลฐานข้อมูล
3. วาง mysql-connector.jar ใน WEB-INF/lib/
4. คอมไพล์ Java files และวาง .class ใน WEB-INF/classes/
5. Deploy chat-jsp ใน Tomcat webapps/
6. เข้าถึง: http://localhost:8080/chat-jsp/
